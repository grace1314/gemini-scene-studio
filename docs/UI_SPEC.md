# 页面设计（实现前确定）

视觉：深蓝灰工程工作台，青绿色主操作，低饱和状态色；顶部阶段导航、场景切换与硬件状态。
主流程严格拆分为：采集 → RGBD 与逐帧选区 → 左目 RGB COLMAP SfM/BA → 点云与 TSDF → 3DGS。窄屏导航折为两列。
无数据时显示说明与导入入口，不显示伪造指标。

| 路由 | 页面 | 主要内容与操作 |
|---|---|---|
| /#/overview | 项目总览 | 真实帧数、完成阶段、资产数、工作流图、最近任务 |
| /#/capture | 采集与数据 | 独立场景创建、无损帧列表、压缩预览、曝光/增益/白平衡锁定 |
| /#/depth | RGBD 与逐帧选区 | BridgeDepth、左侧帧列表、RGB 多边形编辑、过滤深度预览、Z 范围与保存 |
| /#/geometry | COLMAP SfM / BA | ALIKED、LightGlue、注册率、重投影误差、米制尺度恢复与分阶段进度 |
| /#/region | 点云与 TSDF | 同一逐帧掩膜的点云/TSDF 串行融合、进度、交互预览与网格下载 |
| /#/tsdf | TSDF融合 | 体素/截断/深度范围、mesh输出、几何预览 |
| /#/train | 3DGS训练 | 步数/高斯上限/深度权重、GPU前置检查、训练日志、结果图与模型 |
| /#/assets | 预览与下载 | 文件类型/大小/所属运行、PLY/NPZ/PNG/JSON下载、归档ZIP |
| /#/system | 环境与模块 | 本地依赖、权重来源与状态、GPU、后端已接入/计划中 |

运行按钮在前置数据缺失时禁用并说明原因。运行中全局串行队列显示进度；可以取消。
切换场景不混用任务状态。每次运行生成新目录，不覆盖旧产物；下游取最近成功且依赖仍有效的运行。
3D预览展示实际点云/网格；Gaussian中心预览与真正splat渲染明确区分。

逐帧多边形只影响点云、TSDF 和 3DGS 监督，不影响相机位姿。每帧可撤销顶点或恢复全画面；保存时一次写入全部帧。点云查看器提供轨道旋转、平移、缩放、聚焦、网格、RGB/纯色、点大小与全屏。SuperSplat 风格的正负笔刷、球形选区和自动语义分割仍属于后续能力。
